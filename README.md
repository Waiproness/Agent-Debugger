# Agent Debugger

เว็บสำหรับตรวจบันทึกการทำงานของ Agent ช่วยดูแต่ละขั้นตอน ค้นหาปัญหา และเปรียบเทียบผลจากสองรัน

**[เปิดเว็บใช้งาน](https://waiproness-agent-debugger.mahidol-univ-1119.chatgpt.site)** — ใช้ได้ทันที ไม่ต้องติดตั้งหรือใช้ API key

ข้อมูล log ประมวลผลและเก็บในเบราว์เซอร์ของคุณ ไม่มีการเรียกโมเดล AI หรือส่ง log ไปยังเซิร์ฟเวอร์

## ทำอะไรได้บ้าง

- ดู Timeline และรายละเอียด input, output และ error ของแต่ละขั้นตอน
- ค้นหาและกรองตามสถานะหรือประเภท
- ดูสรุป error ขั้นตอนที่ใช้เวลานาน และ Tool ที่เรียกซ้ำ
- เปรียบเทียบรัน A/B พร้อมแสดงข้อมูลที่เปลี่ยน
- ส่งออก JSON พร้อมตัวเลือกปกปิดข้อมูลลับ

## เริ่มใช้งาน

1. เปิดเว็บ แล้วกด **โหลดรันตัวอย่าง** เพื่อทดลอง
2. ถ้ามี log ของตัวเอง กด **เลือกไฟล์ JSON** ตรวจ preview แล้วกดยืนยันนำเข้า
3. เลือกรันและขั้นตอนที่ต้องการตรวจ หรือเปิดโหมด **เปรียบเทียบสองรัน**

รองรับไฟล์ Agent Debugger v1 และ OTLP JSON บางรูปแบบ ขนาดไม่เกิน **10 MiB** ดู [ไฟล์ตัวอย่าง](public/examples) และ [JSON Schema](schema/agent-log-v1.schema.json)

## รันบนเครื่องสำหรับพัฒนา

ต้องมี Git, Node.js 24 ขึ้นไป และ npm จากนั้นเปิด Terminal แล้วรัน:

```sh
git clone https://github.com/Waiproness/Agent-Debugger.git
cd Agent-Debugger
npm ci
npm run dev
```

เปิด http://127.0.0.1:5173/ และหยุดเซิร์ฟเวอร์ด้วย Ctrl+C

ถ้ามีโปรเจกต์อยู่แล้ว ให้เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วเริ่มจาก `npm ci`

## ตรวจสอบและ build

```sh
npm test
npm run build
```

คำสั่ง build ตรวจ TypeScript และสร้างไฟล์พร้อมเผยแพร่ไว้ใน `dist/` ใช้ `npm run preview` เพื่อเปิดดู build บนเครื่อง

## ข้อควรรู้

- ข้อมูลบันทึกใน IndexedDB เฉพาะเบราว์เซอร์และที่อยู่เว็บนั้น ไม่ซิงก์ข้ามเครื่อง ควรส่งออกสำรองก่อนล้างข้อมูลเว็บไซต์
- ข้อมูล IndexedDB รุ่นเดิมย้ายให้อัตโนมัติ หากย้ายไม่สำเร็จจะเก็บฐานเดิมไว้
- OTLP ต้องมี root เดียวต่อ trace, parent ครบ และสถานะ OK/ERROR ชัดเจน ข้อมูลที่แปลงไม่ได้จะถูกปฏิเสธพร้อมเหตุผล
- การปกปิดข้อมูลใช้กฎตรวจจับ อาจพบข้อมูลลับไม่ครบทุกชนิด ควรตรวจไฟล์ก่อนส่งต่อ

รายละเอียดการทดสอบ ประสิทธิภาพ และข้อจำกัดเพิ่มเติมอยู่ใน [ผล QA](docs/readiness-qa.md)
